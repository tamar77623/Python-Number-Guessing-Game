# 🎯 Python Number Guessing Game

A simple number guessing game built with Python.

The computer randomly selects a number between 1 and 10, and the player has three attempts to guess it correctly.

## 🚀 Features

- Random number generation.
- Three guessing attempts.
- Input validation for numbers outside the range.
- Helpful hints: Too High and Too Low.
- Win and Game Over messages.

## 🛠️ Technologies

- Python
- Random module

## 🎮 How to Play

1. Run the Python program.
2. Enter a number between 1 and 10.
3. Try to guess the computer's number within three valid attempts.
4. Win by guessing correctly!

## 💻 How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

## 📚 Purpose

This project was created as a Python learning exercise to practice functions, loops, conditional statements, user input, and random number generation.
